# Incipit

Strumenti per analizzare i procedimenti amministrativi dei comuni italiani.

| Cartella | Cosa contiene |
|---|---|
| [`raccolta-albo/`](raccolta-albo/) | Raccolta giornaliera degli atti dall'albo pretorio e dallo storico atti (piattaforma JCityGov), e prima analisi per comune |
| [`design/`](design/) | Token CSS, font, logo e icone del design system |
| [`report/`](report/) | Generatore della pagina del report di analisi degli atti (HTML autonomo con il design system). Dati e testi stanno nel repo privato |

I dati raccolti **non** stanno in questo repository: gli atti possono contenere
dati personali e restano in un repository privato separato.
